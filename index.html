房產傳承五問
取得背景 → 移轉選擇 → 家人分配 → 現金缺口
① 這間房現在是誰的？當初怎麼來？什麼時候取得？
先問所有權，再分取得方式與時間，判斷未來出售稅制
現在是誰的？
自己的 → 當初是買的、受贈的，還是繼承的？
父母的 → 父母希望怎麼安排？誰有權決定？
共同持有 → 跟誰共有？各占多少？誰在使用？延伸 → 接到第③問，討論共有與分配
買賣取得 → 什麼時候買的？
104／12／31以前取得 → 以現在出售一般住宅而言，原則適用舊制，房屋財產交易所得併入綜合所得
105／1／1起取得 → 原則適用房地合一稅新制
贈與取得 → 誰贈與的？什麼時候受贈？
一般受贈，如父母贈與子女：104／12／31以前受贈 → 現在出售原則適用舊制
一般受贈：105／1／1起受贈 → 原則適用新制，不能直接沿用父母原買入日期
配偶贈與 → 另依配偶間首次贈與前的原始取得日及取得原因判斷
繼承取得 → 被繼承人何時取得這一筆房地或持分？
被繼承人於104／12／31以前取得 → 原則適用舊制
被繼承人於105／1／1起取得 → 原則適用新制
連續繼承、分次取得 → 分筆、分持分判斷，不能一律追溯最早一代的買入日
舊制繼承房地若符合自住房地等法定條件，可另評估選擇新制
承接｜「同樣把房子留給孩子，取得方式不同，未來賣掉後能留下的錢也可能不同」延伸 → 接第②問，比較現在移轉與未來繼承，再估分配資金
追問｜房貸還有多少？現在由誰繳？缺口 → 繳款的人離開，家人未必有能力接手保險切入 → 檢視身故保障與剩餘房貸是否匹配
追問｜除了這間房，還有多少可動用現金？缺口 → 資產集中房產，臨時用錢可能被迫出售保險切入 → 盤點既有保單，評估傳承時的現金需求
追問｜家人生活是否靠房租或屋主收入？缺口 → 貸款、扶養與生活費可能同時壓上來保險切入 → 檢視家庭收入中斷的保障
② 想現在過戶，還是百年後繼承？
比較移轉當下稅費、孩子將來出售稅負，以及父母的生活保障
現在贈與子女 → 先算移轉成本
贈與稅 → 分年贈與，可評估年度免稅額115年度每位贈與人全年合計244萬元，不是每個孩子各244萬元，也不是房屋市價直接套免稅額
土地增值稅 → 一般應稅住宅基地，原則按一般用地稅率贈與不能適用自用住宅優惠稅率，並非「一半稅率」；另有法定免徵或不課徵情形，須分案確認
房屋契稅與登記費用 → 一起納入估算
孩子將來出售 → 取得日與成本認定，也要一併比較
百年後繼承 → 再算分配與資金
繼承移轉當下 → 土地免徵土地增值稅，房屋免徵契稅
整體遺產 → 仍須評估遺產稅、負債與處理費用
日後再出售 → 仍須另判斷土地增值稅與所得稅，並非永遠免稅
承接｜「移轉當下稅費少，不代表家人之後就容易分，您希望這間房最後給誰？」延伸 → 接第③問
追問｜現在過戶後，自己住哪裡？生活費從哪裡來？缺口 → 房子給出去了，自己卻沒有足夠退休現金保險切入 → 先保留生活與醫療預備金，再評估退休現金流安排
追問｜如果留到繼承，家人有錢辦稅與處理分配嗎？缺口 → 房產留下來，現金卻沒有同步準備保險切入 → 評估壽險能否補足身後資金缺口
追問｜這個安排預計幾年後完成？目前健康與預算如何？缺口 → 規劃時間與可負擔保費，可能不支持原先想法保險切入 → 先檢視既有保障，再評估投保條件與繳費能力
③ 房子最後希望給誰？
給特定家人，還是共同繼承？先把未來生活情境攤開
如果打算共同繼承 → 六個情境追問
各自成家｜「兄弟姊妹會一直住在一起嗎？各自成家後，對這間房的想法還會相同嗎？」
一人居住｜「如果只有一個人住，其他人同意嗎？要不要約定使用方式或補償？」
占用爭議｜「如果有人不同意，是否會為搬離、使用補償或相當租金的請求而起爭執？」是否能請求及金額，須看使用約定、占有依據與個案事實
維修整修｜「漏水修繕誰付？大整修誰決定？按持分、使用情形，還是另有約定？」
出售與保留｜「一個想賣、一個想留時，誰有錢承接？談不攏怎麼處理？」
下一代加入｜「其中一人先過世，持分再傳下去，之後要跟多少人協商？」
承接｜「如果希望房子留給真正需要的人，其他家人也有安排，我們就要先想：沒拿房子的人，拿什麼？」延伸 → 接第④問，討論房產與現金分配；共有是否適合，仍依家庭目標與共識評估
追問｜給一個孩子，是因為他自住、照顧父母，還是接班？缺口 → 有指定對象，卻沒準備其他家人的分配資金保險切入 → 評估以身故保險金安排其他家人的現金需求
追問｜房子給孩子後，另一半還要住多久？生活費夠嗎？缺口 → 有房可住，仍可能缺少日常生活現金保險切入 → 盤點配偶可取得的保障與生活資金
追問｜對方適合一次拿到大筆錢嗎？缺口 → 想照顧長期生活，卻擔心一次領完後花光保險切入 → 評估分期給付機制或保險金信託
④ 沒拿房子的家人，要拿什麼？
釐清分配落差 → 找出需要補上的現金
追問｜如果一人拿房、其他人拿錢，預計各安排多少？缺口 → 有分配想法，卻沒有對應的現金資產保險切入 → 評估壽險作為分配資金的一部分，搭配遺囑與整體法律安排檢視
追問｜如果大家共有，有人想退出時，誰有錢買下持分？缺口 → 想保留房子的人，可能無力支付其他人的對價保險切入 → 配合整體分配方案，評估取得持分所需的資金
追問｜家人認為的公平，是金額相同，還是各自有需要？缺口 → 父母的心意與家人的期待可能不同保險切入 → 先確認分配共識，再討論保額與受益人安排
⑤ 稅金、費用與補償的現金在哪裡？
把前四問加總 → 從「有沒有保險」走向「現金夠不夠」
追問｜稅費、貸款、生活費與分配資金，各需要多少？缺口 → 只想到稅金，漏掉債務、家人生活與分配需求保險切入 → 分項估算用途，避免重複計算需求
追問｜現金在誰手上？到時候誰能領到、何時能用？缺口 → 家裡有資產，不代表需要用錢的人拿得到保險切入 → 檢視保單關係人、受益人與給付條件
追問｜扣掉可用現金與既有保障，還差多少？缺口 → 傳承需要的錢，超過現有可動用資金保險切入 → 依缺口、健康與預算，評估適合的保障方案
收斂提問｜「如果希望房子照您的意思留下來，又不用家人臨時湊錢，我們先一起算出還差多少現金，好嗎？」
稅制範圍｜以115年規劃、一般個人住宅房地為主；特殊取得原因與歷史交易另判斷，保險安排依核保、契約及稅務條件評估
