# 房產傳承五問

手機與桌面皆可使用的房產傳承提問工具

## 兩種使用模式

- 客戶盤點：逐步整理房產取得、移轉時點、家人分配與現金缺口
- 業務引導：每題另附延伸追問與保險需求方向
- 完整心智圖：可展開取得方式、稅制判斷及共有情境
- 提問摘要：可複製或列印，方便與顧問討論

## 啟用網頁

在 GitHub 儲存庫中，開啟 Settings → Pages

1. Source 選擇 Deploy from a branch
2. Branch 選擇 main，資料夾選擇 / (root)
3. 按 Save，等候 GitHub Pages 部署
4. 以 Pages 設定頁實際顯示的網站網址為準

網站網址加上 `?role=client` 可直接進入客戶盤點，加上 `?role=advisor` 可直接進入業務引導；網頁也提供複製模式連結按鈕

兩個模式是公開的顯示選項，沒有帳號或權限隔離

## 資料與維護

所有填答僅保留於本次頁面的記憶體，重新整理即清除，不自動傳送或儲存；使用者可自行複製或列印摘要

單一 index.html 即可運作，無須安裝套件、伺服器或資料庫

## 使用範圍

稅務說明以民國115年規劃的一般住宅房地為主，官方資料連結列於網頁；特殊取得原因、連續繼承或分次取得持分需另行判斷

現金缺口盤點不是稅額試算，亦不代表核保或給付承諾
